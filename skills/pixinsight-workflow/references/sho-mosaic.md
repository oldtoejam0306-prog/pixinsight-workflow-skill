# SHO / HOO 与马赛克

单片跳过拼接。HOO 按真实 Hα/OIII 通道处理，不补造 SII。SHO 初始可用 SII→R、Hα→G、OIII→B；后期映射/混合须记录，窄带映射色彩不等于宽带真实色彩。

## 逐片到统一坐标

1. 清点每片每通道线性 master、星点配准、曝光、信号与有效边缘。确认重叠/朝向，不凭文件夹 1/2 直接上下拼图。
2. 只处理确认存在的梯度；检查模型，避免减掉满场发射星云，不强求所有区域等亮/中性。
3. 在适用的 BXT 流程中逐片 Correct Only，暂不主要锐化/强混色。核实当前工具指导与历史，避免重复处理。
4. 校正后定位，建立统一投影、尺度和网格。同片通道共享 WCS 须有配准证据；减少重采样，修整无效插值边缘。
5. 按工具与重叠质量选择 PhotometricMosaic 或合适替代，逐波段匹配亮度/相对梯度，使用共同坐标与有效裁切。
6. 检查强显示拉伸单通道、彩色全图与 1:1 接缝：重影、双星、亮度台阶和色断层。拼接合格后才推进后期。

## 完整图后期

- 在线性、有星点、未强混色的完整窄带图比较正式反卷积，检查暗柱、细丝、弱 OIII 与亮星；无额外收益选较轻档。
- 分离星点，按信号强弱选择亮度/色彩降噪；保护 OIII/SII 独有结构，合成亮度不能让全图只剩 Hα 形态。
- 比较 MAS/GHS 等对外围、亮部、暗柱的效果；有依据才混合候选，记录阶段。历史混合比例不作默认。
- 可沿用用户认可的金铜/青蓝方向，保持柔和过渡。NBN 等明确调色板与输入阶段，不套用宽带 SPCC 中性标准。
- 色度/局部对比受真实信号与蒙版约束；弱背景紫绿噪声不视为星云色彩。
- 星点独立拉伸调色后合成，局部处理亮星紫晕。只有窄带数据时明确星色局限；真实 RGB 星色需额外 RGB 素材。

最终复核接缝、外围、暗柱、星点、有效边缘和 WCS。保留通道/拼接检查点，改颜色时无需重跑整个拼接。
